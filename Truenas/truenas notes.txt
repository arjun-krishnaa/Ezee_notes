installation guide

TrueNAS (CORE or SCALE) requires a 64-bit x86_64 CPU, at least 8GB of RAM (16GB+ recommended), a dedicated 16GB+ SSD for the boot drive, and separate drives for data storage. You will also need a USB stick for the installer, an Ethernet connection, and a compatible motherboard without RAID controllers interfering with ZFS.

Hardware & Software Prerequisites

Processor: 64-bit Intel or AMD CPU (dual-core minimum, 4-6+ cores recommended).
Memory (RAM): 8GB minimum (ECC RAM is strongly preferred for data integrity).
Boot Drive: A dedicated SSD/HDD (16GB minimum, 32GB+ recommended). USB sticks are not recommended for long-term boot use due to high write endurance needs.
Storage Drives: One or more SATA/SAS drives for data. For redundancy, at least two identical drives are recommended (e.g., ZFS Mirror). Avoid SMR (Shingled Magnetic Recording) drives.
Installation Media: A USB stick for the TrueNAS ISO and a tool like BalenaEtcher.
Networking: Wired Ethernet (Gigabit or faster). Wireless is not supported.
BIOS/UEFI: SATA controllers should be in AHCI or IT mode (JBOD), not hardware RAID mode.

------------------------------------------------------------------------------------

Installation Steps

Download the ISO image from the TrueNAS website.
Use BalenaEtcher to flash the ISO to a USB stick.
Connect the USB stick to the target machine and boot from it.
Select "Install/Upgrade" and follow the installer prompts.
Set a strong root password.
Reboot and access the management interface via web browser.
