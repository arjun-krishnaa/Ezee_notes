# ❌ Error

```
ERROR 6125 (HY000):
Failed to add the foreign key constraint.
Missing unique key for constraint
'fk_namespace_cancellation_policy_cancellation_policy_group1'
in the referenced table 'cancellation_policy_group'
```

---

# 🔍 Root Cause

You’re trying to create a **foreign key** that references a column in:

```
cancellation_policy_group
```

👉 But that referenced column is **NOT indexed as PRIMARY KEY or UNIQUE**

---

# 🧠 Rule in MySQL

A foreign key **must reference**:

* ✅ PRIMARY KEY
* ✅ or UNIQUE KEY

❌ Cannot reference a normal column
