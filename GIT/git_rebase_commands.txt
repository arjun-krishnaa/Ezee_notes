```bash
# Check current branch
git branch

# Switch to live-agent branch
git checkout live-agent

# Fetch latest changes from remote
git fetch origin

# Pull with rebase
git pull --rebase origin live-agent
```

If you already have local changes, stash them first:

```bash
git stash
git pull --rebase origin live-agent
git stash pop
```

If any conflict occurs during rebase:

```bash
# After resolving conflicts
git add .

# Continue rebase
git rebase --continue
```

To cancel the rebase:

```bash
git rebase --abort
```
